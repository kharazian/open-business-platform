|---|---|---|---|

| Trends | Business/operational trends, budget comparison, diagnostics | Verified | Standard analytics and bounded visuals. |

| Presentation | Focus mode, copy link, state handling, responsive cards | Verified | Escape exits focus mode. |
| Authoring | Section CRUD/order/icons; widget add/duplicate/drag/move/remove/resection/resize | Verified | Visual canvas provides section/widget drag handles, drop zones, and button/select fallbacks. |
| Publishing | Draft/publish/unpublish, slug, navigation, permission | Verified | Existing audited lifecycle reused. |
| Safety | 16 sections, 48 widgets, 16/section, 8 filters | Verified | Server validator and tests enforce limits. |
| Localization | Locale-aware number/date formatting | Implemented | Translation keys for sample prose remain a localization backlog item. |
| Drill-through | Typed source-record and saved-report destinations with serialized scalar filters | Verified | Destination APIs recheck current form/report, record-scope, and field permissions; arbitrary URLs and cross-source mappings are not supported. |
| URL filter state | Shareable query parameters | Verified | Versioned `dv=1` state preserves an allowlisted active section and bounded schema-defined filter values; malformed sections, dates, values, and unsupported options are ignored. |
| Full widget editor | Edit analytics/adapter definitions after creation | Verified | Responsive drawer edits content, layout, source/report, analytics properties, table columns, and adapter settings with capability validation and live preview. |
| Configured series charts | Add, remove, reorder, label, style, color, axis, direction, and Bar layout for one to four metrics | Verified | Single and multi-series breakdown/trend charts honor bar/line/area display metadata; compatible category Bar series support vertical/horizontal grouped, cumulative stacked, and percentage-stacked layouts; permission-filtered single-series breakdowns also support accessible, interactive pie/donut proportions, while combo charts use independent left/right scales. |
| Category ordering | Source order, combined value ascending/descending, or label A-Z/Z-A | Verified | Ordering is presentation-only over the bounded breakdown response and is shared by cartesian, pie, and donut renderers; trends remain chronological. |
| Top categories and Other | Show 1-12 leading returned categories and optionally aggregate the remainder | Verified | Combined multi-series values choose the shared Top-N order; additive count/sum series aggregate independently while averages disable Other, Other stays last, and aggregate selection cannot create a false scalar drill-through filter. |
| Axis titles and scale | Optional active-axis titles and automatic/manual positive maxima | Verified | Vertical and horizontal renderers preserve zero baselines, clamp geometry to manual maxima, disclose clipping, and keep 100% stacks fixed at 100%. |
| Chart appearance | Palette, responsive legend placement, data-label content/placement, gridlines, card accent, localized number formats, and display units | Verified | Bounded theme/cool/warm/monochrome presets, top/bottom/left/right legends, value/percentage label content, automatic/inside/outside cartesian placement, and unscaled/automatic/K/M/B units are saved per analytics widget; circular labels remain collision-safe and presentation settings never alter source data. |
| Reference and target lines | Up to four labeled values with color, style, and left/right scale | Verified | Bar/line/area scaling includes each bounded nonnegative reference value; KPI, table, pie, and donut configurations are rejected, and lines remain presentation-only. |
| KPI conditional status | Up to five ordered numeric rules with semantic accents, readable labels, and a static fallback | Verified | First-match evaluation is shared by editor preview and published viewer; required 1-80 character labels prevent color-only meaning, and the backend rejects invalid operators, colors, labels, bounds, duplicate IDs, excessive rules, and non-KPI use. |
| KPI targets and variance | Optional labeled target with localized variance, goal direction, outcome, and progress | Verified | Higher/lower-is-better semantics produce readable favorable/on-target/needs-attention results; nonzero targets use percentage variance, zero targets use an absolute difference, and valid nonnegative ratios render bounded progress. |
| KPI period comparison | Permission-scoped previous-period trend for UTC 7/30/90-day windows | Verified | A reportable date field defines equal current/previous windows; the backend preserves other filters and authorization, returns aggregates only, and the shared card renderer shows readable up/down/unchanged text. |
| Add-widget wizard | Source-first guided creation, searchable gallery, recommendations, preview, and recent choices | Verified | Recommendations use already-loaded reportable field capabilities; the final sample preview and add action reuse the permission-checked analytics endpoint. |
| Canvas productivity | Undo/redo, multi-select, bulk actions, section duplication/collapse, density, and zoom | Verified | Draft-only history is bounded to 30 snapshots; bulk and duplicate operations preserve the 16-section/48-widget/16-per-section server limits. |
| Filter authoring | Source/field/control editor, option preview, default values, required/optional state, and per-widget targeting | Verified | Backend revalidates filter ids, field compatibility, defaults, options, and same-source targets before persistence. |
| Fixed widget filters | Per-widget multi-value choice and date-range constraints with saved-config precedence over same-field dashboard filters | Verified | Accessible option toggles, OR-within-field semantics, ordered inclusive-start/exclusive-end dates, backend schema/option validation, permission-scoped execution, cloning, and Operations module scoping are covered by focused tests. |
| Chart interactions | Keyboard/click selection, native SVG tooltips, table-row selection, optional new-tab navigation | Verified | Point filters derive only from the configured grouping/date field; table rows use typed record-detail routes. |
| Dashboard library | Search, lifecycle badges, duplication, and archive | Verified | Published directory search is client-bounded; duplication creates an independent draft; archive uses permission-protected audited soft deletion and immediately removes live exposure. |
| Sharing | Workspace, specific user/role/group audience, private, and unlisted links | Verified | Subject IDs are manager-only metadata; published snapshots enforce OR membership checks and unauthorized reads return 404. |
| Server adapter registry | Built-in adapter visualization and setting allowlists | Verified | `sample-dashboard` IDs/keys are backend allowlisted; unknown built-in config is rejected while safe scalar legacy adapter definitions remain backward compatible. |
| Recycle bin | Search, archive actor/time, safe draft restore, guarded permanent deletion | Verified | Manager-only endpoints and UI enforce concurrency, exact-name confirmation, a configurable 30-day production wait, audit continuity, and no automatic purge. |
| Cross-source calculations | Joins/formulas across sources | Deferred | Excluded to preserve permissions and avoid arbitrary SQL. |
